# ShadowFox Cybersecurity Internship

This repository contains the tasks completed during my ShadowFox Cybersecurity Internship.

The internship involved practical cybersecurity tasks related to network reconnaissance, web application enumeration, and network traffic analysis.

## Tasks

### Task 1 — Port Scanning

Used Nmap to identify open ports and running services on the designated vulnerable web application.

Topics covered:

- Port scanning
- Open ports
- Service detection
- Nmap -sV

### Task 2 — Directory Enumeration

Performed directory and file enumeration to discover accessible and restricted resources on the web application.

Topics covered:

- Directory enumeration
- Wordlists
- HTTP status codes
- 200, 301 and 403 responses

### Task 3 — Wireshark Network Analysis

Used Wireshark to capture and analyze HTTP network traffic generated while interacting with the web application.

Topics covered:

- Packet capture
- HTTP traffic
- Wireshark filters
- HTTP requests and responses
- Network traffic analysis

## Tools Used

- Nmap
- Gobuster / Dirbuster
- Wireshark

## Disclaimer

All activities in this repository were performed as part of the ShadowFox cybersecurity internship using the designated vulnerable training environment.

The techniques and tools were used for educational and authorized security testing purposes only.
